# DeepSeek V4 Flash EXL3 — multi-seq on one DGX Spark

OpenAI-compatible serving of **DeepSeek V4 Flash 0731 (EXL3)** on a single **NVIDIA DGX Spark**, tuned for **concurrent sequences** (agents / parallel chats) rather than max single-context depth.

Based on [MiaAI-Lab/DeepSeek-v4-Flash-One-DGX-Spark](https://github.com/MiaAI-Lab/DeepSeek-v4-Flash-One-DGX-Spark). This repo keeps that launcher and adds [`start-multi.sh`](start-multi.sh).

| Launcher | Profile | Port |
|----------|---------|------|
| **`./start-multi.sh`** (recommended here) | **8** concurrent seqs, **256k** context, DSpark K5 | **8001** |
| `./start.sh` | Upstream deep-context: **1** seq, **384k** context | **8888** |

Model: [`0xSero/deepseek-v4-flash-0731-spark`](https://huggingface.co/0xSero/deepseek-v4-flash-0731-spark) (EXL3 3.0 bpw, REAP-K216) via sparkinfer / DSpark.

## Quick start

```bash
git clone https://github.com/rimusz/DeepSeek-v4-Flash-One-DGX-Spark.git
cd DeepSeek-v4-Flash-One-DGX-Spark
./download.sh          # optional offline prep (~107 GB) — or let first boot download
./start-multi.sh
curl -sf http://127.0.0.1:8001/v1/models
```

First boot pulls the image, downloads weights into `./hf-hub`, coalesces TP1, builds the K64 draft, and captures CUDA graphs. It is healthy when the OpenAI endpoint responds.

```bash
./start-multi.sh --no-wait   # start without waiting for healthy
./stop.sh                    # stop
```

`compose.yml` is generated by the launcher (gitignored). Do not hand-edit it.

### Overrides

```bash
MAX_NUM_SEQS=4 ./start-multi.sh
MAX_MODEL_LEN=192000 SERVING_PORT=8001 ./start-multi.sh
```

| Variable | `start-multi.sh` default | Notes |
|----------|--------------------------|-------|
| `MAX_NUM_SEQS` | `8` | concurrent sequences |
| `MAX_MODEL_LEN` | `256000` | per-sequence context ceiling |
| `SERVING_PORT` | `8001` | OpenAI-compatible port |
| `DSPARK_TOKENS` | `5` | DSpark speculation depth (K) |
| `MAX_NUM_BATCHED_TOKENS` | `8224` | leave alone — load-bearing for MLA workspace |
| `CUDAGRAPH_CAPTURE_SIZES` | `8,16,48` | derived from seqs × K |

Upstream deep-context profile (unchanged):

```bash
./start.sh                 # 1 seq / 384k / :8888
# or: MAX_NUM_SEQS=1 MAX_MODEL_LEN=384000 SERVING_PORT=8888 ./start.sh
```

See [MiaAI’s README](https://github.com/MiaAI-Lab/DeepSeek-v4-Flash-One-DGX-Spark) for their 384k stress-test numbers and KV-pool notes.

## Requirements

- One NVIDIA DGX Spark (GB10 / SM121, ≥128 GiB unified memory)
- Linux aarch64 (DGX OS), Docker Engine + Compose v2, `curl`, ~110+ GiB free disk
- Disable EarlyOOM if present: `sudo systemctl disable --now earlyoom`
- Internet for the one-time ~107 GB Hugging Face download (or use `./download.sh` beforehand)

## Client configuration

| Setting | Multi-seq (`start-multi.sh`) | Upstream (`start.sh`) |
|---------|------------------------------|------------------------|
| Base URL | `http://127.0.0.1:8001/v1` | `http://127.0.0.1:8888/v1` |
| Model id | `deepseek-v4-flash-0731` | same |
| Context window | up to **256000** | up to **384000** |
| Concurrent clients | up to **8** seqs | **1** seq |

Binds `0.0.0.0` by default (`network_mode: host`). No auth on the port — keep it on a trusted network, or `SERVING_HOST=127.0.0.1 ./start-multi.sh`.

## What’s in this tree

Same packaging as MiaAI’s recipe: `start.sh` / `stop.sh` / `download.sh`, `image-patch/` bind-mounts, optional `ABLATE` refusal-direction hook (`files/direction_r1.pt`).

This repo’s addition is only **`start-multi.sh`** (+ this README): env defaults and CUDA-graph sizes for 8-way concurrent serving on one Spark.
