# DeepSeek V4 Flash EXL3 — 8 concurrent seqs on one DGX Spark

OpenAI-compatible serving of **DeepSeek V4 Flash 0731 (EXL3)** on a single **NVIDIA DGX Spark**, configured for **8 concurrent sequences** (agents / parallel chats).

| Setting | Default |
|---------|---------|
| Concurrent sequences | **8** |
| Context per sequence | **256000** |
| Port | **8001** |
| Speculative decoding | DSpark **K5** |
| CUDA graphs | **8, 16, 48** |

Model: [`0xSero/deepseek-v4-flash-0731-spark`](https://huggingface.co/0xSero/deepseek-v4-flash-0731-spark) (EXL3 3.0 bpw, REAP-K216) via sparkinfer / DSpark.

Packaging based on [MiaAI-Lab/DeepSeek-v4-Flash-One-DGX-Spark](https://github.com/MiaAI-Lab/DeepSeek-v4-Flash-One-DGX-Spark); this repo’s launcher defaults are multi-seq only.

---

## Quick start

```bash
git clone https://github.com/rimusz/DeepSeek-v4-Flash-One-DGX-Spark.git
cd DeepSeek-v4-Flash-One-DGX-Spark
./download.sh          # optional offline prep (~107 GB) — or let first boot download
./start.sh
curl -sf http://127.0.0.1:8001/v1/models
```

First boot pulls the image, downloads weights into `./hf-hub`, coalesces TP1, builds the K64 draft, and captures CUDA graphs. It is healthy when the OpenAI endpoint responds.

```bash
./start.sh --no-wait
./stop.sh
```

`compose.yml` is generated by `start.sh` (gitignored). Do not hand-edit it.

### Overrides

```bash
MAX_NUM_SEQS=4 ./start.sh
MAX_MODEL_LEN=192000 ./start.sh
```

| Variable | Default | Notes |
|----------|---------|-------|
| `MAX_NUM_SEQS` | `8` | concurrent sequences |
| `MAX_MODEL_LEN` | `256000` | per-sequence context ceiling |
| `SERVING_PORT` | `8001` | OpenAI-compatible port |
| `DSPARK_TOKENS` | `5` | DSpark speculation depth (K); engine floor is K5 |
| `MAX_NUM_BATCHED_TOKENS` | `8224` | leave alone — load-bearing for MLA workspace |
| `CUDAGRAPH_CAPTURE_SIZES` | `8,16,48` | seqs, 2×seqs, seqs×(K+1) |

---

## Requirements

- One NVIDIA DGX Spark (GB10 / SM121, ≥128 GiB unified memory)
- Linux aarch64 (DGX OS), Docker Engine + Compose v2, `curl`, ~110+ GiB free disk
- Disable EarlyOOM if present: `sudo systemctl disable --now earlyoom`
- Internet for the one-time ~107 GB Hugging Face download (or use `./download.sh` beforehand)

---

## Client configuration

| Setting | Value |
|---------|-------|
| Base URL | `http://127.0.0.1:8001/v1` |
| Model id | `deepseek-v4-flash-0731` |
| Context window | up to **256000** |
| Concurrent clients | up to **8** seqs |

Binds `0.0.0.0` by default (`network_mode: host`). No auth on the port — keep it on a trusted network, or `SERVING_HOST=127.0.0.1 ./start.sh`.
